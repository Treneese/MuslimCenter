# Muslim Center

> **A modern digital platform for mosque and community management.**

The Muslim Center platform is a full-stack web application designed to help mosques better serve their communities through modern technology. It centralizes prayer times, events, donations, announcements, and administrative tools into one easy-to-manage platform.

This repository contains the complete Muslim Center application, including the public website and backend management system.

---

# Vision

The goal of Muslim Center is to provide mosques with an affordable, modern platform that simplifies administration while strengthening community engagement.

By reducing administrative overhead and improving communication, community leaders can spend more time serving their members.

---

# Platform Components

## Client

The public-facing website used by community members.

Features include:

- Home page
- Prayer Times
- Iqamah Times
- Programs
- Events
- Donations
- Contact
- Announcements

---

## Server

Backend services responsible for:

- Event management
- Prayer management
- Contact submissions
- Administrative tools
- Database management
- API services
